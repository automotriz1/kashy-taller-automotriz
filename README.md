Este repositorio representa el punto de presencia digital y geolocalización de **Taller Automotriz El Kashy**. Combinamos el trabajo mecánico artesanal y especializado con herramientas digitales modernas para ofrecer un servicio transparente, rápido y confiable a nuestra comunidad.

## Servicios Especializados
* **Cambio de Aceite y Filtros:** Mantenimiento preventivo para maximizar la vida útil del motor.
* **Sistema de Frenos:** Inspección, rectificación y cambio de pastillas/discos para tu seguridad.
* **Mecánica General:** Diagnóstico integral, reparación de motor, suspensión y transmisión.
* **Sistema Eléctrico:** Revisión de batería, alternador, cableado y diagnóstico de fallas mecánicas/eléctricas.
